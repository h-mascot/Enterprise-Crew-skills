# Source Checklist

## Public Sources

- Official conference website
- Official agenda/program PDF
- Speaker list
- Sponsor/exhibitor list
- Venue page
- Press releases and post-event summaries
- Company websites for target accounts
- Public LinkedIn/company pages when needed

## Internal Sources

- `memory/` and QMD search
- Fireflies transcripts
- Gmail and Calendar
- Shuttle/CRM
- Prior conference packs
- Beeper/WhatsApp/iMessage relationship context
- Google Drive/Sheets

## Source Labels

Use these labels in prep packs:

- `official`: conference organizer source
- `public`: public web source, not necessarily organizer-owned
- `internal`: user/team workspace, CRM, memory, email, calendar, or transcript
- `provided`: user-provided file/export/screenshot
- `inferred`: reasoned from evidence, not directly stated
- `missing`: needed but not found

## Verification Rules

- Every event fact needs a source URL/path.
- Distinguish speaker list from attendee list.
- Do not claim private attendee coverage without export/app access.
- If sources disagree, record both and prefer the official source.
- If the event is already over, use post-event source material only for retrospective facts, not pre-event availability.
