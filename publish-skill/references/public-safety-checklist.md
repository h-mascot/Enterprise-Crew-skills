# Public safety checklist

Before publishing any skill externally, verify:

- No secrets, tokens, API keys, private keys, cookies, `.env` files, or password examples.
- No personal home paths, private IPs, internal hostnames, or customer identifiers.
- No raw private chat transcripts, screenshots, logs, or local session data.
- Public examples use placeholders such as `/path/to/skill`, `user@example.com`, and `<REDACTED_TOKEN>`.
- ClawHub publish uses CLI/API token auth without printing token values.
